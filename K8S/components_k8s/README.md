# Задание. Необходимо определить требуемые ресурсы
Предположим что наши виртуалки нарезаны по 4cpu 8gb

**Шаг 1: Расчет необходимых ресурсов**
База данных:
ОЗУ: 12 ГБ
Ядра: 3 ядра
Система кэширования:
ОЗУ: 12 ГБ
Ядра: 3 ядра
Фронтенд:
ОЗУ: 0.25 ГБ (250 МБ)
Ядра: 1 ядро
Бекенд:
ОЗУ: 6 ГБ
Ядра: 10 ядер
Общие ресурсы

**Теперь суммируем все необходимые ресурсы:**

Итого ОЗУ:
12+12+0.25+6 = 30.25 ГБ
Итого ядер:
3+3+1+10 = 17 ядер

**Шаг 2: Расчет количества необходимых узлов**

Характеристики узла:
ОЗУ: 8 ГБ
CPU: 4 ядра

Нод для ОЗУ = 30.25 / 8 ≈ 3.7 узла

Нод для CPU = 17 / 4 = 4.25 узла


**Шаг 3: Служебные ресурсы**

Обычно рекомендуется резервировать около 20% ресурсов для системных и служебных задач:

Дополнительные ресурсы ОЗУ:
Дополнительная память=30.25 ГБ × 0.2 = 6.05 ГБ

Дополнительные ресурсы CPU:
Дополнительные ядра = 17 ядер × 0.2 = 3.4 ядер ≈ 4 ядра

**Общий расчет ресурсов с учетом служебных**

Итого требуемое ОЗУ с запасом:

30.25 ГБ + 6.05 ГБ = 36.30 ГБ

Итого требуемые ядра с запасом:

17 ядер + 4 ядра = 21 ядро

Пересчет узлов с учетом служебных ресурсов
Количество узлов по ОЗУ:

Нод для ОЗУ= 36.30 ГБ / 8 ГБ ≈ 4.5 узлов

Количество узлов по ядрам:

Нод для ядер = 21 ядер / 4 ядра = 5.25 узлов

**Шаг 4: Итог**
С учетом всех расчетов, включая резерв на отказ и служебные ресурсы:
Добавляем один дополнительный узел для обеспечения отказоустойчивости
Необходимое количество узлов: 6.25
